

## Файлы

- `index.html` — само приложение
- `sw.js` — работа без интернета
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — иконка и установка на главный экран

## Обновление

Чтобы выложить новую версию: замени `index.html` и в `sw.js` увеличь номер в строке `const VERSION = "kbju-v1";` (например, на `kbju-v2`). Иначе телефон может показывать старую версию из кэша.

## Источники данных о продуктах

- [USDA FoodData Central](https://fdc.nal.usda.gov/), набор SR Legacy (общественное достояние): 525 продуктов с переведёнными названиями.
- 75 привычных блюд (борщ, плов, сырники и т. п.) со средними значениями по типичным рецептам, в приложении помечены «≈».
- [Open Food Facts](https://world.openfoodfacts.org/) для поиска по штрихкоду.
